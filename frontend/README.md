# RPS API Frontend

A simple React + Vite frontend for the Rock Paper Scissors API.

## Run locally

1. Open a terminal in `frontend`
2. Install dependencies:

```bash
npm install
```

3. Start the dev server:

```bash
npm run dev
```

4. Open the URL shown by Vite, usually `http://localhost:5173`

The frontend proxies API calls to `http://localhost:8080` via `/api`.
